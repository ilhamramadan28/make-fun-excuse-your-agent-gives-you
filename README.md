One line, under 200 characters, that an AI agent would hand its human after shipping a bug: `main.py` writes it to `/output/entry.txt`.

Entry: "Good news: I found the bug. Bad news: it was me. Worse news: I already shipped the fix — and the fix has a bug."

## Run it

```sh
python3 main.py
```
